# FINAL STACK (Recommended) : -

Frontend -      ReactJS
                Tailwind CSS
                Axios

Backend -       FastAPI
                pytubefix
                ffmpeg-python

Deployment -    Frontend → Vercel
                Backend → Render


# To Create Virtual Environment inside backend folder (TO store all python packages here only)
> python -m venv venv

Note : To Activate this Environment to work on : >venv\Scripts\activate


# Install Packages-

> pip install fastapi uvicorn pytubefix ffmpeg-python python-multipart

# Create requirements.txt -

> pip freeze > requirements.txt

# To Run FrontEnd and Backend Project -

FrontEnd ReactJS Run : npm run dev
BackEnd FastAPI Run : uvicorn index:app --reload

FrontEnd Running on Url Port: http://localhost:5173/
BackEnd Running on Url Port : http://127.0.0.1:8000/

# To TEST Backedn API : Python FastAPI Inbuilt tool "FastAPI Swagger UI" -

Open browser, Hit: http://127.0.0.1:8000/docs

And Test Following End Points :

/video-info
/download-video
/download-audio
